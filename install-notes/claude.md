# Add AI community prep to Claude

This works in Claude on the web and in the desktop app. You need the file ai-community-prep.zip, which sits next to this note. Do not unzip it.

1. Sign in to Claude.
2. In the left menu, click Customize, then click Skills.
3. Click Add at the top right, then click Upload skill.
4. Choose ai-community-prep.zip from your computer, then click Upload.
5. Claude runs a security scan on the file as it uploads. Wait for it to finish.
6. Make sure the switch next to the new skill is on.

## Check that it installed
The skill appears in your list as ai-community-prep. That is AI community prep. Click it and the Overview tab shows its description.

## Start it the first time
Open a new chat and type: "Open AI community prep and let's start." It is listed as ai-community-prep, so you can ask for it by either name.

## How to read the file yourself
The skill is plain text. Unzip it, open the ai-community-prep folder, and open SKILL.md in a text editor. Nothing in it is hidden. It never sends, uploads, or fetches anything, and you can skip any step.

## If you do not see the upload option
Your company may have turned off personal uploads. Two ways forward:
1. Ask your Claude admin to add AI community prep for the whole company. Send them the zip.
2. Use the paste fallback note we included. It should work in any assistant. If your company turned uploads off on purpose, check with your IT lead first.

## If the upload is rejected
Unzip the file, open the ai-community-prep folder, and upload the file SKILL.md instead. If that fails too, use the paste fallback note we included.
