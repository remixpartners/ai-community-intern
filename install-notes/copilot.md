# Add AI community intern to Microsoft 365 Copilot

This note is for Copilot Cowork. You need the file ai-community-intern.zip, which sits next to this note. Do not unzip it.

1. Open Microsoft 365 Copilot and expand the sidebar.
2. At the top of the sidebar, switch the toggle from Chat to Cowork.
3. In the left rail, click Customize.
4. Click Add at the top right, then click Upload.
5. Drop ai-community-intern.zip into the box, or choose it from your computer. Copilot accepts .MD, .ZIP, or .SKILL files.
6. You see "Uploading your skill" and then "Skill uploaded."

## Check that it installed
AI community intern is listed under Added as ai-community-intern. Start a new conversation before you test it.

## Start it the first time
In a new conversation, type: "Use AI community intern and let's start." It is listed as ai-community-intern, so you can ask for it by either name.

## How to read the file yourself
Unzip it, open the ai-community-intern folder, and open SKILL.md in a text editor. It is plain text. It never sends, uploads, or fetches anything, and you can skip any step.

## If the upload is rejected
Unzip the file, open the ai-community-intern folder, and upload the file SKILL.md instead. If that fails too, use the paste fallback note we included.

## If you do not see these options
Your admin may have limited custom skills, or Cowork may not be switched on for you. If the Cowork toggle or the Upload option is missing, ask your admin, or use the paste fallback note we included. It should work in any assistant. If your company turned uploads off on purpose, check with your IT lead first.
