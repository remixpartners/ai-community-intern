# Use AI community prep without installing anything

This should work in any AI assistant, including ones where uploads are blocked; we have tested it in one so far. If your company turned uploads off on purpose, check with your IT lead first. Nothing else changes. AI community prep still never sends, uploads, or fetches anything, and you can skip any step.

1. Find SKILL.md. It sits next to the zip; if you only have the zip, unzip it and open the ai-community-prep folder.
2. Open SKILL.md in any text editor, such as Notepad or TextEdit, or in your browser.
3. Select all of the text and copy it.
4. Open a new chat in your assistant.
5. Paste the whole text into the message box.
6. At the end, add one line that says: Start AI community prep now.
7. Send it all as one message.

## How to read the file yourself
Everything the assistant will follow is in that one file. Unzip it, open the ai-community-prep folder, and open SKILL.md in a text editor. Read it before you paste it. It is plain text, and nothing is hidden in the zip.

## Good to know
1. Paste the text again each time you open a new chat. The assistant does not keep it between chats.
2. If the assistant says the message is too long, try a newer model or a different assistant.
3. Keep the pasted chat private to you, as you would any work document.
