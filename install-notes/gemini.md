# Add AI community prep to Gemini

Gemini does not accept the zip. Unzip ai-community-prep.zip first, then upload the file inside it. A copy of that file, SKILL.md, also sits next to the zip, so you can use it directly.

1. Unzip ai-community-prep.zip. You get a folder named ai-community-prep with one file inside, SKILL.md.
2. Open Gemini and sign in.
3. In the left rail, click Customize (the gear-like icon), then open the Skills tab.
4. Click the small arrow next to Create, then click Upload.
5. Click to choose files and pick SKILL.md from the ai-community-prep folder.
6. Gemini opens an editor showing the Name, Description, and Instructions it read from the file. Click Create at the top right to save it.

Skills are still rolling out in Gemini, so some accounts do not show the Skills tab yet. If yours does not, use the paste fallback note we included.

## Check that it installed
A "Skill created" message appears. AI community prep is listed under Active as ai-community-prep.

## Start it the first time
Open a new chat and type a forward slash, then ai-community-prep, then a space and "let's start", so the message reads: /ai-community-prep let's start

Asking for it by name in plain words may not open it in Gemini; in testing it started a web search instead.

Our own test runs in Gemini did not get past the first reply. Until that is sorted, use the paste fallback note we included.

## How to read the file yourself
Open SKILL.md from the ai-community-prep folder in a text editor. It is plain text. It never sends, uploads, or fetches anything, and you can skip any step.

## If you do not see the option

1. Check again in a few weeks, or ask your Google Workspace admin.
2. Use the paste fallback note we included. It should work in any assistant. If your company turned uploads off on purpose, check with your IT lead first.
