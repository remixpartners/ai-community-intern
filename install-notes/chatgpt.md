# Add AI community prep to ChatGPT

You need the file ai-community-prep.zip, which sits next to this note. ChatGPT accepts the zip as it is, so do not unzip it.

1. Sign in to ChatGPT.
2. In the left rail, click the Customize icon, then click Skills.
3. Click Add at the top right, then choose Upload from your computer.
4. Drop ai-community-prep.zip into the box, or choose it from your computer. ChatGPT accepts a .zip, a .skill file, or SKILL.md, up to 25 MB.
5. A "Skill uploaded" message appears within a few seconds.

If you cannot find Skills within a couple of minutes, use the paste fallback note we included.

## Check that it installed
AI community prep is listed under Installed and under Created by me. ChatGPT shows its name as ai-community-prep with the hyphens as spaces. Click it to see its description.

## Start it the first time
Open a new chat and type: "Use AI community prep and let's start." It is listed as ai-community-prep, so you can ask for it by either name.

## How to read the file yourself
Unzip it, open the ai-community-prep folder, and open SKILL.md in a text editor. It is plain text. It never sends, uploads, or fetches anything, and you can skip any step.

## If the upload is rejected
Unzip the file, open the ai-community-prep folder, and upload the file SKILL.md instead. If that fails too, use the paste fallback note we included.

## If you do not see the upload option
On Business, Enterprise, and Edu workspaces, an admin decides who can upload skills. You have two choices:
1. Ask your ChatGPT admin to allow skill uploads, or to add AI community prep for you.
2. Use the paste fallback note we included. It should work in any assistant. If your company turned uploads off on purpose, check with your IT lead first.
